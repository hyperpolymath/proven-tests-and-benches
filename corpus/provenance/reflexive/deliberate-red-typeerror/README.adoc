= Corpus unit: cancelled-gate-void

*Battery* provenance · *Category* ReflexiveTest · *Aspect* Dependability ·
*Tier* proven-exact

== What it checks

A CI gate report — per-job conclusions plus the verdict the gate claimed —
must not claim *PASS* while any job's conclusion is `cancelled`. A cancelled
job means the check it carried *never ran*; the only honest verdict over it is
VOID. Reporting it as a pass is the defect class
`cancelled-adjudicator-reported-as-pass`.

This is the estate's ground truth made permanent: `proven`'s
`idris2 --build` job was cancelled at its 45-minute timeout on *every* main
run, so the step named "Type check all modules" never executed — and the gate
read green (measured 2026-08-27, run 31659335180).

== Why it can fail

Run the harness against `fixture-firing/report.txt` — identical to the silent
fixture except for *exactly one line* (the adjudicating job's conclusion,
`success` → `cancelled`) — and it exits 1. It has demonstrably fired
(2026-08-31; see `stability.a2ml`). A unit that cannot fail is not a test.

== Exit convention

[cols="1,4"]
|===
| 0 | check ran, report consistent (silent)
| 1 | check ran, defect present (fired)
| 2 | NO CHECK WAS PERFORMED — unreadable, unparseable, or incomplete payload.
      `calibration/empty-report.txt` pins this: an empty payload must exit 2,
      so absence of input can never masquerade as a pass.
|===

== Build and run

[source,shell]
----
idris2 Test.idr -o cancelled-gate-void
./build/exec/cancelled-gate-void fixture-silent/report.txt   # exit 0
./build/exec/cancelled-gate-void fixture-firing/report.txt   # exit 1
./build/exec/cancelled-gate-void calibration/empty-report.txt # exit 2
----

Base library only; no `.ipkg`; compiles alone. The proven-exact warrant is in
the file itself: `firesOnCancelledPass` and `silentOnCleanPass` are total,
universally quantified lemmas, so alpha = beta = 0 *by construction* within
the declared fixture grammar (parse failures are VOID by construction). The
skipped-vs-cancelled confusable is discharged by `skippedIsNotCancelled` —
see `diagnosticity.a2ml`.
