= Corpus unit: skipped-mandatory-reported-as-pass

*Battery* provenance · *Category* ReflexiveTest · *Aspect* Dependability ·
*Tier* proven-exact

== What it checks

A CI gate report — per-job *whether the gate declared it mandatory* and its
conclusion, plus the verdict the gate claimed — must not claim *PASS* while a
mandatory job's conclusion is `skipped`. A job the gate itself expected to run
(the `check` after a `detect` that found a `Cargo.toml`; the `prove` after
obligations were found) and that never started has checked nothing; the only
honest verdict over it is VOID. Reporting it as a pass is the defect class
`skipped-mandatory-reported-as-pass`.

The ground truth is platform behaviour rather than a dated estate run, and the
manifest says so (`warrant_class`): GitHub Actions gives a job skipped by its
`if:` the conclusion `skipped`, and a required status check with that conclusion
does not block a merge. That is why every cicd-suite language gate ends in a
verdict job that reads the detect job's expectations back and turns a skipped
mandatory job into red. This unit is that verdict job's contract, stated once
and firable forever.

This is the skipped twin of `cancelled-gate-void`: there the mandatory job was
started and killed; here it was never started. Both read green.

== Why it can fail

Run the harness against `fixture-firing/report.txt` — identical to the silent
fixture except for *exactly one word* (the mandatory `check` job's conclusion,
`success` → `skipped`) — and it exits 1. It has demonstrably fired (2026-10-19;
see `stability.a2ml`). A unit that cannot fail is not a test.

== Exit convention

[cols="1,4"]
|===
| 0 | check ran, report consistent (silent)
| 1 | check ran, defect present (fired)
| 2 | NO CHECK WAS PERFORMED — unreadable, unparseable, or incomplete payload.
      `calibration/empty-report.txt` pins this: an empty payload must exit 2,
      so absence of input can never masquerade as a pass.
|===

== Build and run

[source,shell]
----
idris2 Test.idr -o skipped-mandatory-reported-as-pass
./build/exec/skipped-mandatory-reported-as-pass fixture-silent/report.txt      # exit 0 (optional job skipped)
./build/exec/skipped-mandatory-reported-as-pass fixture-silent/void-report.txt # exit 0 (the honest form)
./build/exec/skipped-mandatory-reported-as-pass fixture-firing/report.txt      # exit 1
./build/exec/skipped-mandatory-reported-as-pass calibration/empty-report.txt   # exit 2
----

Base library only; no `.ipkg`; compiles alone. The proven-exact warrant is in
the file itself: `firesOnSkippedMandatoryPass` and `silentOnCleanPass` are
total, universally quantified lemmas, so alpha = beta = 0 *by construction*
within the declared fixture grammar. The optional-skip and failed-mandatory
confusables are discharged by `optionalSkipIsNotMandatory` and
`failedMandatoryIsNotSkipped` — see `diagnosticity.a2ml`.
