= Proven-Tests: State of Things (Honest Gap Analysis)
:toc: left
:toclevels: 3
:sectnums:

== Purpose

This is a repo-local, honest assessment of how far Proven-Tests currently lives
up to the standard in `CHARACTERISTICS.adoc`, in the spirit of `AUDIT.adoc`
(claims must not outrun evidence). It is a working document: update it as gaps
close.

It records the *categories* the project defines, *what exists and works*, *what
does not exist or does not work*, and the *general state*.

== Verdict (current)

*Early alpha — the library compiles, runs honest-green (10/10), and is gated by
real CI.* Still ungraded / "X" on the Component Readiness Grade scale until the
empty categories and missing artifacts are addressed.

What changed in this pass (all verified against Idris2 0.7.0 locally):

* The library *compiles end to end*: `idris2 --build proven-tests.ipkg` builds all
  16 modules cleanly.
* *Provenance is now load-bearing* (see section 2): you cannot construct an
  Actually-/Provisionally-Proven classification without supplying the evidence.
* The *benchmark harness is now honest* (see section 3): real monotonic-clock
  timing, non-memoised workloads, dead-code-elimination defeated.
* The executable runs and all `10/10` suites pass; it exits non-zero if any suite
  fails, so CI gates on the result (see section 9).
* CI now actually compiles and runs the framework — a GitHub Actions workflow plus
  a GitLab `idris2` job — instead of skipping everything (see section 5).

The conceptual architecture remains the strong part. The remaining gaps are the
empty test categories, the un-built `tests/TypeSafeTests` modules, and several
missing referenced artifacts.

== What we have (real)

* *The taxonomy above*, cleanly modelled as Idris2 algebraic data types with
  `Show`/`Eq` instances and enumerations (`Types.idr`, `Taxonomy.idr`).
* *A compiling library* — all 16 modules build under Idris2 0.7.0.
* *Evidence-carrying provenance* — the headline feature is now enforced by the
  type system (see section 2).
* *Nine TypeSafe modules plus a runner* containing genuine, non-decorative
  property logic. All suites pass at runtime (10/10 including self-classification).
* *An honest benchmark* (`benchmarks/Benchmark.idr` + `benchmark.ipkg`) reporting
  real ns/iteration with a printed checksum.
* *The Zigzag regimen* (`src/ProvenTests/Zigzag.idr` + `docs/ZIGZAG-REGIMEN.adoc`)
  — an organising principle: a co-phase x actor x category x aspect lattice
  (3570 coordinates) with a boustrophedon traversal, exercised on every run.
* *A machine-checked tropical (min-plus) semiring* (`src/ProvenTests/Tropical.idr`)
  — total Idris2 proofs of the `⊕`/`⊗` laws, the shared algebra behind
  bag-of-actions' cheapest-capable routing and proven-tests' resource bounds.
  This is the framework's *first genuinely Actually-Proven test* (real proofs,
  not sampling), surfaced via `ProvenTests.Baton.tropicalLawsClassification`.
* *The cross-repo Baton contract* (`src/ProvenTests/Baton.idr` +
  `docs/CROSS-REPO-UNIFICATION.adoc`) — `BatonSpec` pairs a Zigzag coordinate,
  an evidence-carrying provenance tier, and a tropical cost, so the honesty
  invariant survives routing across the bag-of-actions mesh.
* *Infrastructure and governance* — devcontainer / Containerfile, pre-commit,
  TruffleHog secret scanning, a rich Justfile, plus GOVERNANCE / AUDIT /
  MAINTAINERS docs and consistent SPDX headers throughout.

== What we do not have / what is broken

Line references are approximate and may drift as fixes land.

=== 1. Compilation — FIXED

The library previously did not compile. The following were repaired so that
`idris2 --build proven-tests.ipkg` now succeeds:

* `benchmarks/Benchmark.idr` — removed `%%access export` (Idris1), the non-Idris2
  `for _ in [1..n] do`, the malformed `( => ...)` lambdas, and `import Data.Time`.
  Rewritten honestly (section 3).
* `Effects.idr` / `Dyadic.idr` — replaced the value-level `=>` / `==>`
  "implication" with real boolean logic; added a missing `Eq Effect`.
* `Report.idr` — removed the duplicate `countResults` and invalid
  `public export [export]`; fixed `testId` -> `test_id`; renamed the reserved
  word `total`.
* `Framework.idr` — replaced the broken computed-type machinery and the dishonest
  `assertNoThrow` with a clean `Runnable` interface; suites now hold mixed-
  provenance tests.
* `Runners.idr` — fixed `if/then/else` layout and reserved-word `total`.
* `Main.idr` — corrected the module name and dropped imports of unbuilt test
  modules.
* TypeSafe modules — added the missing `import ProvenTests.Classification`; fixed
  `Dependent`'s malformed `DepPair` kind and type-case pattern, `Decorative`'s
  Idris1 `class`/`instance`, `Ceremonial`'s `last` clash, and `Bridge`'s GADT
  header / `.startsWith` / `Eq TypeSafeCategory`.

=== 2. Provenance — FIXED (now load-bearing)

`classifyActuallyProven` previously accepted a proof ladder, design proof, and
certificate and *discarded all of them*, returning a bare label. Now
`Provenance` carries its justification as a typed payload, and the constructors
*require* that evidence:

[source,idris]
----
data Provenance : Type where
  PUnproven            : Provenance
  PProvisionallyProven : ProvisionalEvidence -> Provenance
  PActuallyProven      : ActualEvidence -> Provenance
----

`ActualEvidence` holds the proof ladder as a non-empty `List1`, so it is
impossible to claim Actually-Proven with zero proof steps. `promote*` functions
now return `Maybe` instead of fabricating a bogus "Cannot promote" record.

=== 3. Benchmarks — FIXED (honest timing)

The old `timeAction` was a mock returning `0`. The harness now uses
`System.Clock` (monotonic), runs index-varied workloads drawn from the real
predicates (`effectStackValid`, `relationTransitive`, `ceremonyEndsProperly`) so
results are not memoised, and folds every result into a printed checksum so the
optimiser cannot elide the work. It reports total and per-iteration nanoseconds.

=== 4. Fourteen test-category directories are empty stubs

`tests/01-unit` ... `tests/14-chaos` each contain only a near-identical
`README.adoc` pointing at a `TESTING-TAXONOMY.adoc` that is not in this
repository. There are zero actual unit / p2p / e2e / ... tests.

=== 5. CI — FIXED (now compiles and runs Idris2)

The Cargo/mix-gated jobs in `.gitlab-ci.yml` still skip on this repo, but there
is now a real `idris2` job (GitLab) plus `.github/workflows/ci.yml` (GitHub
Actions). Both bootstrap Idris2 from source and run `scripts/ci-build.sh`:
compile the library, install it, build the benchmark, then run the suite (which
exits non-zero on failure) and the benchmark. CI is now load-bearing.

To avoid metered GitHub-hosted minutes, the GitHub Actions workflow is
*manual-only* (`workflow_dispatch`); the GitLab job is the hosted gate. For a
zero-minute required check, `scripts/owned-compute-gate.sh` runs the same checks
on owned compute and posts the verdict as a GitHub commit status (the in-repo
embodiment of bag-of-actions' `Bag.GitHubBridge`). See `docs/ZERO-MINUTE-CI.adoc`.

=== 6. Missing referenced artifacts

* `echo-types-integration/` — referenced by README, absent.
* `READINESS.adoc` — the Justfile `crg-badge` / `crg-grade` recipes depend on it,
  absent.
* `standards/.../TESTING-TAXONOMY.adoc` — the canonical taxonomy the stubs point
  at, absent from this repo.
* README installation says `ipkg.json`; the actual file is `proven-tests.ipkg`.

=== 7. Taxonomy <-> folders mismatch

The code defines 17 test categories but `tests/` has 14 numbered directories.
Compatibility, Proof-Regression, and Type-Safe have no numbered home (Type-Safe
lives separately under `tests/TypeSafeTests/`).

=== 8. The tests/TypeSafeTests modules are not in any build target

Nine test files under `tests/TypeSafeTests/` exist but are not part of the
`.ipkg`, so they are never compiled or run. They need a dedicated test package.

=== 9. Four category suites — FIXED (10/10 now pass)

These previously failed and have been corrected *without weakening assertions*:

* *Tropical* — `tropicalMinIdentity` now uses the correct min-plus additive
  identity (`+infinity`) instead of `0`.
* *Effects* / *Epistemic* — the runners no longer apply *every* predicate to
  *every* sample state; each state-specific property is now asserted against the
  input where it is meant to hold (e.g. `effectOrderMatters` only on empty /
  State-headed stacks; declassification-to-CONFIDENTIAL only on the PUBLIC state).
* *Bridge* — passes now that the three above do.

=== 10. The category and aspect axes are decorative (the Zigzag lattice is empty)

`TestAspect` (14) and `TestCategory` (17) are clean types in `Taxonomy.idr`, but
`TestMetadata` stores `aspect : Maybe String` and `category : Maybe String`
(stringly-typed, *not* the enums) and every classifier sets both to `Nothing`.
So no test declares a category or aspect, and the 17x14 = 238 cell matrix is
entirely unpopulated. The `EndToEnd` category in particular has no tests
(`tests/03-e2e/` is a stub), and the framework's own end-to-end run is never
tagged with a coordinate.

The *Zigzag regimen* (`docs/ZIGZAG-REGIMEN.adoc`, `src/ProvenTests/Zigzag.idr`)
is the response: it names the full `co-phase x actor x category x aspect` lattice
(3570 coordinates) and the order in which to populate it. The principle is
encoded and runnable; wiring it into `TestMetadata` (typed axes + a coordinate)
and populating cells is tracked below.

== Reproducing the local build

[source,bash]
----
# Requires Idris2 >= 0.7.0 (with chez backend), GMP, and the chez runtime support.
idris2 --build   proven-tests.ipkg            # compile the library + executable
idris2 --install proven-tests.ipkg            # install so the benchmark can depend on it
idris2 --build   benchmarks/benchmark.ipkg    # compile the benchmark
./build/exec/proven-tests                      # run the suites (10/10) + zigzag summary
./benchmarks/build/exec/proven-bench           # run the benchmarks
----
