== The doubt check

D-1: "doubt check" is not defined in this repo or in `metadatastician/standards` (searched both for `doubt`; only an unrelated licence text matched). The best honest reading, implemented in
`scripts/agda-doubt-check.sh`: a source-level audit for every place a proof can quietly stop being a proof (postulate, TERMINATING and similar pragmas, type-in-type, unsound flags, trustMe, REWRITE, holes, FOREIGN/COMPILE, and a file whose own OPTIONS pragma does not state `--safe --cubical-compatible`), with justified exceptions listed in an allow file. If the owner meant something else (for example a runtime "second look" step, or a check on the Idris2 side), this needs one line from the owner; nothing downstream depends on it yet.
