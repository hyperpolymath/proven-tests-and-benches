# Support

- **Questions / discussion:** open a GitHub issue (no template needed).
- **Defects — including overclaims:** the *Defect* issue template. A document
  asserting what nothing computes is as much a bug here as a crash.
- **Offering a test back** (the taxonomy's contribution flow): the *Test
  contribution* template, with the harness/payload split filled in.
- **Security:** see `SECURITY.md` — do not open a public issue.
- **Orientation:** `README.adoc` → the "Where to look next" table; agents read
  `AGENTS.md` first.
