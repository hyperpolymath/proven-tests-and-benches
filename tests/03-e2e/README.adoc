= E2E Tests

**Category:** E2e
**Source:** standards/testing-and-benchmarking/TESTING-TAXONOMY.adoc
**Directory:** 03-e2e/

**Purpose:** See TESTING-TAXONOMY.adoc for detailed description

**Status:** The first real E2E test lives at `src/ProvenTests/E2E.idr` (built and
run by the package, since the `tests/NN-*` directories are not yet a build
target). It occupies Zigzag coordinate (CoImplementation, Collective, EndToEnd,
Dependability) and runs an inner suite through `Framework.runSuite`. New E2E
cells should follow it until these directories are wired into a test package.

**Files:** All tests in this directory are Idris2 implementations

**To add a test:**
1. Create a new file: 03-e2e/MyTest.idr
2. Follow Idris2 test conventions
3. Add to test runner
